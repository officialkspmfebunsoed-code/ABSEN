Panduan Instal Aplikasi

Jadikan web ini sebagai aplikasi di HP-mu.

Instal di Android (Chrome)

  1. Buka web absen ini menggunakan browser Google Chrome.
  2. Tekan ikon Titik Tiga (⋮) di pojok kanan atas browser.
  3. Pilih opsi "Tambahkan ke Layar Utama" (Add to Home Screen) atau "Instal Aplikasi".
  4. Aplikasi Absen KSPM kini muncul di daftar aplikasi / menu HP-mu layaknya aplikasi biasa!

Instal di iPhone / iOS (Safari)

  1. Buka web absen ini menggunakan browser bawaan Safari.
  2. Tekan tombol Share (Bagikan) berupa kotak dengan panah ke atas di bagian bawah layar.
  3. Gulir daftar opsi ke bawah lalu pilih "Tambah ke Layar Utama" (Add to Home Screen).
  4. Tekan "Tambah" (Add) di pojok kanan atas.
  5. Selesai! Buka aplikasi dari Home Screen untuk mendapatkan fitur notifikasi alarm penuh (mulai iOS 16.4+).
